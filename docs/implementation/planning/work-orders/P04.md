# P04 — Implement the deterministic entity and event kernel

- Issue: [#8](https://github.com/MaximilianMauroner/dps.lol/issues/8)
- Issue body revision: `2026-09-18T20:10:16Z`
- Owner lane: Engine kernel worker
- Prerequisites: P01
- Owned paths: `src/domain/engine/kernel/**`, `tests/engine/kernel/**`

## Deliverables

Implement entity/team/ownership state, a monotonic integer clock, stable event identities,
scheduling/cancellation, spawn/despawn, pure dispatch and causal lineage. Define same-time,
expiry, death, periodic, projectile and checkpoint semantics. Bound events/branches and serialize
incremental sessions; exhaustion returns typed incomplete/invalid state rather than a score.

## Acceptance

Insertion order cannot change timestamp order or deterministic ties. A future W event leaves current
health unchanged until execution. Cancel/reschedule, same-time scheduling, lifecycle changes and
checkpoint/resume are reproducible and independent of wall-clock/network state.
