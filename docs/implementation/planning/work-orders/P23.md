## Deliverables

Extract a generic reducer/controller and isolated champion, level, ranks, runes, inventory-lock,
budget and scenario panels using P01 fixtures. Support test/fight modes, advanced entities,
policies and positioning. Preserve manual edits across refreshes and expose explicit observed-default
reset and provenance. Keep mock data confined to test/story fixtures.

## Acceptance

Level changes cannot overwrite locked/user-authored state without a declared action. Controls
serialize to valid ScenarioSpec with resolved defaults/provenance. Keyboard, narrow-screen,
invalid-input and empty-data behavior is covered.
