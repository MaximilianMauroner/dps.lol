## Acceptance

The release bundle identifies code, ruleset, schema, source artifacts, tests and deployment config
without secrets. Backup/rollback evidence is real and archive-only recovery is not treated as a DB
backup. No production migration, deletion, retention change, unbounded ingestion, deployment or
paid service occurs without explicit authorization.
