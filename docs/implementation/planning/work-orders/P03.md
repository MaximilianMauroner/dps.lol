# P03 — Build independent mechanic validation and observation tooling

- Issue: [#7](https://github.com/MaximilianMauroner/dps.lol/issues/7)

- Owner lane: Validation worker
- Prerequisites: P01
- Owned paths: `tests/engine-harness/**`, `tests/observations/**`,
  `scripts/validate-mechanics.ts`, `docs/validation/**`

## Deliverables

Create engine-independent fixtures, trace/numeric/property/mutation assertions and observation
records. Define controlled in-game protocols with patch, state, timings, targets, repetitions and
captured evidence. Separate observed, synthetic and legacy fixtures; require independent review for
disputed behavior. Classify discrepancies as input, source-version, timing/rounding,
implementation or unobserved behavior.

## Acceptance

Incorrect modifiers, event order and proc counts are caught. No fixture becomes an observation
without source identity and record. The harness works with P01 contract fixtures and later with the
real engine without changing facts.
