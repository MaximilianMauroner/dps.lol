# P10 — Implement shared triggers, proc chains and event lineage

- Issue: [#14](https://github.com/MaximilianMauroner/dps.lol/issues/14)
- Issue body revision: `2026-09-18T20:10:23Z`
- Owner lane: Trigger worker
- Prerequisites: P05, P06, P09
- Owned paths: `src/domain/engine/triggers/**`, `tests/engine/triggers/**`

## Deliverables

Implement typed on-attack, attack-complete, on-hit, spell-hit, critical, damage, heal, shield, kill
and lifecycle triggers. Enforce internal cooldowns, per-target/owner limits, stacks, marks,
secondary-hit rules and recursion protection. Route chains through shared services and support
copy/possession/transform commands without champion-ID branches in the executor.

## Acceptance

Trigger families cover recursion, prevention, secondary bolts, periodic effects, target switches and
same-time events. Invalid loops fail diagnostically. Item mechanics do not live in champion-owned
damage loops, and lineage/state survive checkpoint/resume.
