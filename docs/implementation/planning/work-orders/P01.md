## Deliverables

Define JSON/structured-clone-safe, runtime-validated RulesetManifest, ScenarioSpec,
ResolvedScenario, EntityState, ItemInstance, ActionPolicy, ObjectiveSpec, SearchConstraints,
EvaluationMode, RunManifest, mechanic evidence, trace and result contracts. Define service and
command/event ports, time units, tie ordering, error semantics, provenance, observed-stat versus
modeled-loadout initialization, worker messages, comparison transfer and legacy boundaries.
Publish fixtures and narrow mock ports; reserve integration files and migration numbering.

## Acceptance

Contracts round-trip without hidden defaults or executable values. Invalid numbers, ranks, item
state, entity references, horizons and schema versions fail clearly. A resolved scenario contains
all replay-affecting values and provenance. Only this owner changes shared contracts.
