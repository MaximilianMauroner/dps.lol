# P05 — Implement composable stats and damage resolution

- Issue: [#9](https://github.com/MaximilianMauroner/dps.lol/issues/9)
- Issue body revision: `2026-09-18T20:10:17Z`
- Owner lane: Stats/damage worker
- Prerequisites: P02, P04
- Owned paths: `src/domain/engine/stats/**`, `src/domain/engine/damage/**`,
  `tests/engine/stats/**`, `tests/engine/damage/**`

## Deliverables

Implement dependency-ordered base/growth/flat/percentage/bonus/conversion stats, caps and floors,
typed damage packets and tags, mitigation, penetration, amplification, shields and attribution.
Keep raw, attempted, absorbed, applied, prevented and overkill values distinct. Support dynamic
state invalidation and reject cyclic conversions. Snapshot targets must not double-count modeled
inventory or buffs.

## Acceptance

Formula tables cover negative resistance, stacking, caps, mixed damage and thresholds. Intermediate
resolution reconciles with totals, and relevant state changes invalidate caches without unnecessary
recomputation.
